# SQL Exploratory Data Analysis Project

This project is about exploring a layoffs dataset using SQL. I used SQL queries to find trends and get insights from the cleaned data.

## What I did

* Found the highest number of layoffs
* Checked layoffs by company and industry
* Analyzed layoffs by year and month
* Compared layoffs by company stage
* Calculated average percentage of layoffs
* Created a rolling total of layoffs over time
* Found the top 5 companies with the most layoffs each year

## SQL used

* `GROUP BY`
* `ORDER BY`
* `SUM()`
* `AVG()`
* `MAX()`
* `MIN()`
* `YEAR()`
* `SUBSTRING()`
* `CTE`
* `DENSE_RANK()`
* Window Functions

## Goal

The main goal of this project was to practice SQL and understand the trends and patterns in the layoffs dataset.
